**인구·설문 기반 시민 페르소나 구축 검증 보고서**

화순군 synthetic citizen 100인 · 데이터 정합성 및 대표성 검증

*담당: 인구데이터 수집·통합 및 페르소나 구축 파트*

**0. 한눈에 보는 결론**

화순군 시민 페르소나 100인은 **실제 화순군 인구구조를 오차 1명 이내
수준으로 재현**했으며, 연령·성비·결측·중복 등 모든 검증 항목에서 문제가
발견되지 않았다. **페르소나 구축 단계로 진행하는 데 대표성 측면의 결함은
없다.**

본 보고서는 (1) 허깅페이스 원천 데이터의 연령 표현 방식, (2) 세
데이터(원천·인구·설문)의 연령 분류 정합성, (3) 층화추출된 100인의 실제
인구 대비 대표성, (4) 성인 최연소(19세) 경계 처리 방식을 순서대로 검증한
결과를 정리한다.

**1. 검증에 사용한 데이터**

| **데이터**            | **내용**                                            | **연령 표현 방식**                               |
|-----------------------|-----------------------------------------------------|--------------------------------------------------|
| **허깅페이스 원천**   | Nemotron-Personas-Korea 중 화순군 후보군 1,230명    | 1세 단위 개별 정수 (19~98세)                     |
| **화순군 인구데이터** | 페르소나 추출 비율의 기준이 되는 집계 인구          | 구간형 7개 (15-19만 5세, 20~60대 10세, 70+ 개방) |
| **설문지표**          | 연령·직업·학력·지역별 태도 응답 (long 포맷 9,722행) | 구간형 7개 (인구데이터와 동일)                   |
| **층화추출 결과**     | 실제 인구 비율대로 뽑은 최종 시민 페르소나 100인    | 개인 100명 (age_group 라벨 부여)                 |

**2. 세 데이터의 연령 분류 정합성**

**2.1 정밀도의 계층 구조**

세 데이터는 나이를 다루는 정밀도가 서로 다른 계층을 이룬다. 허깅페이스
원천이 가장 촘촘하고(1세 단위), 인구데이터와 설문지표는 동일한 7개
구간으로 이미 묶여 있다.

- **허깅페이스:** 1세 단위 개별값이라 어떤 구간으로도 재집계 가능한 가장
  유연한 원천.

- **인구데이터 · 설문지표:** 7개 구간 정의가 완전히 일치 → 연령대별
  인구수와 연령대별 태도를 손실 없이 조인 가능.

**2.2 파이프라인 연결**

이 계층 구조 덕분에 **「HF 개인(1세) → 인구데이터 구간(뽑을 인원 결정) →
설문지표 구간(태도 부여)」** 로 세 데이터가 하나의 파이프라인으로
자연스럽게 연결된다. 인구데이터와 설문지표의 구간 정의가 동일하기 때문에
매핑 과정에서 손실이 발생하지 않는다.

**3. 층화추출 100인의 대표성 검증**

**3.1 연령대 비율 — 실제 인구와의 일치도**

실제 화순군 인구 비율로 산정한 기대 인원과 실제 추출된 인원을 비교한
결과, 모든 연령대에서 편차가 1명 미만이었다. 이는 반올림 오차 수준으로,
층화추출이 정상 작동했음을 의미한다.

| **연령대**       | **실제 인구 비율** | **기대 인원(100명)** | **실제 추출 인원** |
|------------------|--------------------|----------------------|--------------------|
| **15-19 (19세)** | 4.50 %             | 4.5명                | 4명                |
| **20대**         | 9.76 %             | 9.8명                | 10명               |
| **30대**         | 8.76 %             | 8.8명                | 8명                |
| **40대**         | 11.24 %            | 11.2명               | 12명               |
| **50대**         | 19.33 %            | 19.3명               | 19명               |
| **60대**         | 21.71 %            | 21.7명               | 22명               |
| **70대 이상**    | 24.70 %            | 24.7명               | 25명               |

**3.2 성비 · 데이터 품질**

- **성비:** 실제 남 49.3% / 여 50.7% ↔ 100인 남 49명 / 여 51명 (오차 1명
  미만).

- **결측치:** 전 컬럼 0건. 빈 페르소나 없음.

- **중복:** uuid 100개 전원 고유. 동일 인물 중복 추출 없음.

- **성별×연령:** 70대+에서 여성이 다소 많은 것은 고령층 여초 현상을
  반영한 것으로, 실제 인구구조와 부합.

**4. 성인 최연소(19세) 경계 처리**

**4.1 배경**

허깅페이스 원천은 19세부터 시작하는 반면, 인구·설문 데이터는 15세부터의
15-19 구간을 갖는다. 두 데이터의 시작 나이를 일치시키기 위해, 인구데이터
15-19 구간에서 19세만 남기고 15~18세는 모집단에서 제외하는 방식을
채택하였다. 화순군 1세 단위 인구현황(2026년 5월 기준, 19세 = 490명)으로
19세 인구를 직접 확인할 수 있었기에 가능한 처리이다.

**4.2 19세 비율 비교**

| **구분**              | **19세 비율 (19세+ 성인 대비)** | **비고**               |
|-----------------------|---------------------------------|------------------------|
| **화순 실제 인구**    | 0.92 %                          | 19세 490명 기준        |
| **허깅페이스 후보군** | 1.22 %                          | 후보군 1,230명 중 15명 |

**4.3 해석 및 결론**

20대 이상 연령대가 대부분 1%p 미만으로 실제 인구와 거의 일치한 것과
달리, 19세는 허깅페이스 쪽이 실제보다 약 0.3%p 높다(상대적으로 약
1.3배). 이는 원천 데이터가 19세부터 시작하는 특성상 젊은층이 19세에
상대적으로 몰려 담긴 데 기인한다.

**다만 이 차이는 페르소나 구축 단계에서 실질적인 문제가 되지 않는다.**
19세를 실제 비율(약 0.9%)대로 반영하면 100인 기준 약 1명 안팎에
불과하여, 절대 규모가 워낙 작기 때문이다. 즉 이 정도의 비율 차이는 100인
구성에서 '1명 대 1명' 수준의 편차로 흡수되며, 최종 페르소나 모집단의
대표성에 유의미한 왜곡을 만들지 않는다. 오히려 15~18세를 제외함으로써
원천 데이터와 나이 정의가 정확히 일치하게 되어, 파이프라인 상 유일하게
어긋나던 지점이 해소되는 이점이 있다.
